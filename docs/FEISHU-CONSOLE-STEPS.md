# 飞书控制台操作清单

这些步骤涉及账号身份与权限，需要由用户在飞书开放平台完成。不要把 App Secret 或 API Key 发到聊天中。

1. 登录飞书开放平台，创建“企业自建应用”，名称建议使用 `My Growth OS`。
2. 在应用能力中添加“机器人”。
3. 申请以下最小权限：读取用户发给机器人的消息、以应用身份发送消息、读取和编辑指定多维表格。
4. 在“事件与回调”中选择“使用长连接接收事件”，订阅 `接收消息 v2.0（im.message.receive_v1）`。
5. 长连接只需要 App ID 和 App Secret，不需要公网地址。第一轮连接测试先不配置 Encrypt Key。
6. 创建一个多维表格 `成长数据库`，表结构参考 `config/bitable-schema.json`。
7. 将应用添加为该多维表格的协作者，只授权这一份表格。
8. 应用完成测试后再发布企业内版本，不要开启不必要的通讯录或全局文档权限。

当前个人版优先使用官方 SDK 长连接，本机启动即可接收消息。以后部署为全天在线服务时，也可以继续使用长连接。

只有改用传统 HTTP 回调时才需要公网 HTTPS 地址，格式为：

```text
https://你的域名/feishu/events
```

本机的 `http://127.0.0.1:4280` 是健康检查地址，不填写到飞书控制台。
